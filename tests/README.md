# Tests

Run before every pull request:

```
node tests/run.mjs
```

It checks the recommendation rules, duration typing and muscle volume, then drives the real app in a headless
Chromium: Hevy import, plan → log → finish, drop sets, rest times, exercise history, Progress tabs and search,
pace chart, run logging, body weight, the Back button, scroll position, backup and restore preview, offline start,
and that the version in More matches `sw.js`. It exits with an error if anything fails.

- **Data**: only fake data, generated by `fixtures.mjs` at test time. No `.csv` or backup file is written to the repo.
- **Needs**: Node 18+ and Playwright with Chromium (`npm i -g playwright && npx playwright install chromium`).
  Nothing here is loaded by the app itself.
